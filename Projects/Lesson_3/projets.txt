# 2. Ton programme sur 8 semaines

1. Semaine 1 — Pokédex CLI
   Construire un programme qui recherche un Pokémon, affiche ses statistiques, ses capacités et son poids.
   Notions : GET, JSON, paramètres d'URL, exceptions, timeout.
2. Semaine 2 — Gestion des utilisateurs
   Utiliser JSONPlaceholder pour rechercher un utilisateur, afficher ses informations et ses publications.
   Notions : GET, routes dynamiques, params, status codes, boucles.
3. Semaine 3 — Recherche avancée
   Créer un moteur de recherche de Pokémon avec filtres et pagination.
   Notions : query parameters, headers, JSON, traitement des données.
4. Semaine 4 — Création de données
   Créer un système permettant d'enregistrer des Pokémon favoris.
   Notions : POST, PUT, DELETE, payload JSON, codes HTTP.
5. Semaine 5 — Client HTTP professionnel
   Construire un client qui communique avec plusieurs API et gère les erreurs réseau.
   Notions : HTTPX, Requests, headers, timeout, exceptions.
6. Semaine 6 — Ton API FastAPI
   Créer une API qui permet de gérer une collection de Pokémon favoris.
   Notions : GET, POST, PUT, DELETE, Pydantic, HTTPException.
7. Semaine 7 — API complète
   Ajouter la recherche, les filtres, la pagination et la validation des données.
   Notions : query parameters, path parameters, validation, status codes.
8. Semaine 8 — Projet final
   Construire un Pokédex complet avec un client HTTPX qui communique avec ton API FastAPI, elle-même connectée à PokeAPI.

# 3. Ton premier exercice à faire cette semaine

Semaine 1 · Niveau débutant/intermédiaire## Mission : construire ton Pokédex interactif

Developing a turn based real-time battle game with Next.js and WebSockets | Jay Gould

[jaygould.co.uk](<https://jaygould.co.uk/2022-03-31-developing-turn-based-real-time-battle-game-next-js-websockets/?utm_source=chatgpt.com>)

Tu dois créer un programme Python qui permet à un utilisateur de rechercher plusieurs Pokémon.

Fonctionnalités obligatoires :

1. Demander le nom d'un Pokémon à l'utilisateur.
2. Faire une requête GET vers PokeAPI.
3. Utiliser `timeout=10`.
4. Vérifier le statut HTTP avec `raise_for_status()`.
5. Récupérer les données JSON.
6. Afficher :
   - Son nom.
   - Son poids.
   - Sa taille.
   - Ses capacités.
   - Ses types.
7. Gérer les erreurs si le Pokémon n'existe pas.
8. Permettre à l'utilisateur de rechercher un autre Pokémon sans relancer le programme.

Bonus :

- Afficher les statistiques de base du Pokémon.
- Afficher son numéro de Pokédex.
- Ajouter une option pour quitter le programme.
- Gérer les erreurs de connexion (`httpx.RequestError`).
